MEDSENTRY - HOW TO RUN (PWA WEB)
=====================================

METHOD 1: Run directly from project root (Recommended)
------------------------------------------------------
1. Build PWA:
   flutter build web --release --base-href /

2. Serve PWA:
   npx serve build\web -s -p 8080

------------------------------------------------------
METHOD 2: If your terminal is inside build\web
------------------------------------------------------
If your terminal path shows: ...\MedSentry\build\web>

Run:
   npx serve -s -p 8080

(Note: Do NOT type "build\web" when you are already inside build\web!)

------------------------------------------------------
METHOD 3: Using http-server
------------------------------------------------------
From project root:
   npx http-server build/web -p 8080 -c-1

From inside build\web:
   npx http-server -p 8080 -c-1
